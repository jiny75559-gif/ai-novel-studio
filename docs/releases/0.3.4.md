# 叙事 AI 小说工作台 v0.3.4 更新报告

适用平台为 Windows 10 / 11 x64。

## 本版变化

- 阅读器支持全书页码和跳页，可在翻页与连续滚动之间切换。PDF 保留原页码和版式。
- 批注窗口可拖动和调整大小，支持按位置或时间排序。阅读设置可导入 TTF 和 OTF 字体，正文与章节标题可分别选用字体。
- 阅读和主导航的折叠偏好会保存。短窗口内可独立滚动侧栏，鼠标和键盘操作均可触及底部入口。
- 完善了模型配置保存提示、生图配置删除确认，以及被作品引用时的提示。

## 安装和更新

- 初次安装时，下载离线安装 ZIP，解压并运行其中的 `AI-Novel-Studio-0.3.4-Setup.exe`。安装包包含 WebView2 离线组件。
- 已安装的用户可以在侧栏的“软件更新”里检查新版，也可通过“选择本地更新包”打开 `AI-Novel-Studio-0.3.4.nsupdate`。升级前可为重要作品导出一份备份。
- 免安装 EXE 适用于已经装有 WebView2 的电脑。各下载文件的 SHA-256 见同页的 `SHA256SUMS.txt`。

## 发布前验证

- 生产前端构建、Lint、28 项前端单测、98 项 Rust 测试及 13 项发布验证工具自测通过。
- 用 0.3.3 正式版从软件界面打开本版签名更新包，签名与安装器完整性校验通过。
- 两个正式版二进制依次打开同一个隔离测试库，正文草稿、历史版本、模型配置、阅读位置、书签及文字和 PDF 批注比对一致。新版实际向本机模拟接口发送了原测试密钥。
- 短窗口和高缩放布局已在模拟视口中验证。干净 Windows 上的断网安装、安装器实际覆盖升级和 Windows 系统级高缩放仍待补测。
