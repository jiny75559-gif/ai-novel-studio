# 写作预设与 SillyTavern 兼容范围 · v0.3.0

入口为“模型与设置 → 管理预设 / 导入酒馆”，独立窗口不改变正文编辑、阅读和其他功能的使用方式。内置三个可编辑模板，也可新建、复制、导入和删除库中的预设。预览使用已保存的作品资料，显示实际消息与生成参数，不请求模型。

## 导入与导出

| 输入 | 处理 |
| --- | --- |
| Chat Completion `prompts` + `prompt_order` | 读取条目和多组顺序；支持全局 100000 组及其他组选择 |
| Prompt Manager `{version,type,data:{prompts,prompt_order}}` | 读取封装；列表中的标准资料标记可补建 |
| system prompt `{name,content}`、主 sysprompt 封装 | 转为主写 system 条目 |
| legacy `main_prompt` / `nsfw_prompt` / `jailbreak_prompt` | 转为可编辑提示词条目，不设置应用题材过滤 |
| 工作台完整预设 JSON | 保留当前顺序组、参数开关、宏策略等工作台设置 |
| 连接地址、模型、密钥、自定义 HTTP 头 | 不导入，仍由作者的模型配置决定 |
| 扩展插件、特殊采样字段、Instruct/backend 模板 | 明确显示兼容提示，不执行扩展代码或伪装为完整支持 |

文件上限 4 MB，最多 512 个条目、32 组顺序。角色、ID、深度等在宿主校验；无效文件不会覆盖已保存预设。导入首先成为编辑草稿，保存才进入库，应用才影响当前作品。

导出酒馆格式会把当前选中的顺序组同时写入全局组，关闭参数覆盖时不导出这些参数。完整 JSON 更适合保留工作台的全部配置。酒馆侧的具体宏和扩展环境仍需作者核对。

## 条目与资料融合

条目支持开关、上移/下移/拖动排序、system/user/assistant 角色、相对位置/历史插入深度和同深度顺序。触发条件可选 normal、continue、regenerate；工作台将后续场景对应 continue，重新生成对应 regenerate。深度按请求中的历史消息计算，数值超出可用历史会限制到实际边界，不等同于酒馆聊天会话的消息数量。

酒馆常见资料标记映射到作品的人物、关系、世界设定、文风、大纲和确认历史。作者剧情资料与改稿作为故事依据，预设控制写法和正文输出。未被启用资料标记包含的必要作品资料由工作流补齐，并在预览给出提示。关闭标记用于调整位置，不会删除既有剧情约束。预设内部互相矛盾的自然语言要求仍应由作者修改，软件不能保证模型解决所有冲突。

正文生成使用预设消息和参数；副 AI 将预设要求作为审稿依据，同时保持 REVIEW_JSON 协议。记忆、文风分析、形象提取和插图场景分析保留原有结构化协议及参数。

## 参数与宏

可覆盖 temperature、top_p、frequency_penalty、presence_penalty、max_tokens、seed 和 stop；输出上限按模型配置选择的 token 字段发送。模型配置关闭输出参数时会显示提示；输出上限低于单场景字数目标时也会提示。服务商是否接受每个字段由其 API 决定，软件不会在失败后自动收费重试。

支持人物/作者/书名/章节、设定/文风/大纲/历史和场景目标等常用宏；支持 `setvar/getvar/hasvar/deletevar/addvar/incvar/decvar` 与 globalvar 对应宏、嵌套 `::` 宏、注释、newline、trim、noop。变量只在本次请求中存在；globalvar 同样隔离于本次请求，不会跨作品或跨章节共享。正文中的宏样式文字不会被执行。

未知宏（包括缺少相应酒馆环境的 `original`）保留字面内容并报告，默认暂停生成；作者可选择保留字面量继续，或者替换宏。预设不执行 JavaScript、STscript、Regex 插件、网络工具与酒馆扩展。

## 保存与恢复

预设库保存在本机 SQLite；作品绑定稳定副本。修改/删除库中的模板不会暗中更改其他作品已应用的副本。“保存并应用”才更新当前作品，“恢复默认工作流”取消绑定。备份带作品预设，不带模型密钥。

任务快照包含所用预设，恢复检查包含预设的上下文哈希。作者更改大纲、已确认资料或预设后，旧任务不能直接拼接新约束；恢复时重新套用原任务对应的生成参数。

验证使用真实桌面宿主、SQLite、凭据库与本地 HTTP 模拟接口；官方 Chat Completion JSON 经界面导入和实际请求检查。真实模型对提示词的遵守程度、具体酒馆插件、所有版本和每家服务商的参数尚未穷尽测试。
