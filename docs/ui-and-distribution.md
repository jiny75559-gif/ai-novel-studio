# 界面与离线发行 · v0.2.1

界面结构参考 [Readest 的 Font & Layout](https://www.readest.com/docs/customization) 和 [Koodo Reader 官方界面展示](https://koodoreader.com/en)，只参考交互与视觉层次，没有复制第三方代码、图标或截图。

统一书架、导航、写作台、设置页的无衬线界面字体与灰蓝配色。正文保留官方 NanoOldSong。阅读页使用单一工具栏，隐藏重复的主工具栏与底栏；字号、行距、缩放、布局与主题放进阅读设置面板，支持外部点击/Esc 关闭与键盘焦点返回。目录以侧面浮层呈现，不挤压双页书本。阅读页纸张淡化装饰阴影，随可用窗口宽高适配；用户缩放基于适配后的尺寸，可继续放大滚动阅读。字号重排仍以正文位置为锚点，测量探针与展示正文样式保持一致。

Windows x64 NSIS 配置使用 `webviewInstallMode: offlineInstaller`，在安装包中嵌入微软官方 WebView2 离线安装程序，缺少组件时运行，不依赖首次安装时联网。实现依据 [Tauri 官方 Windows 发行说明](https://v2.tauri.app/distribute/windows-installer/#offline-installer)。应用与 SQLite 本地存储已编译进发行程序，用户不需要 Node.js、Rust、Python。AI 写作仍需用户配置模型服务，ComfyUI/WebUI 模型由用户已有服务提供，未在应用安装包内捆绑模型。

发行压缩包包含安装程序、中文使用说明、字体许可与界面预览；不含开发依赖、个人作品、数据库或 API 密钥。安装包面向 Windows 10/11 64 位，未声明支持 macOS、Linux 或原生 ARM64。

人物形象支持主 AI 读取小说正文，输出外貌与逐字原文引用；首次空形象卡定妆前自动读取指定人物，批量读取结果可修改后采用。原文中出现的新人物可以一并补建卡片。已有定妆图不可被提取结果覆盖；本章换装等以独立变化写入，从原文所在章生效。提取只送当前及之前章节，受模型上下文窗口约束的省略会明确提示。采用时重新核对原文与 SHA-256；正文已修改则拒绝采用过期结果。人物、形象、变化在一次项目事务中保存，失败不部分写入。候选引用校验是文字一致性校验，外貌与人物的语义对应仍需作者校对。
