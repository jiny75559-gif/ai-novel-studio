## 真实桌面程序

运行最终发行的 EXE，使用真实 Tauri WebView、Rust 宿主、SQLite 和 Windows 凭据库。Playwright 通过 WebView2 CDP 连接，不替换 Tauri invoke，不用浏览器 localStorage，不用前端假响应。AI 服务是 `scripts/mock-ai.mjs` 的本地 HTTP 接口，测试不会调用付费服务。

`desktop-e2e.mjs` 的 14 个检查点通过：

1. 实际 UI 创建三章示例并保存数据库。
2. 宿主测试连接真实请求本地兼容接口。
3. 只生成第一章，第二、三章保持空白。
4. 未确认正文点击下一章，显示作者确认提示。
5. 手动改稿保存成新版本，原稿内容不变。
6. 副 AI 检出灯塔重燃和人物知识冲突，来源与引文核实。
7. 定点修订生成分支，作者其他改动保留，当前稿不被覆盖。
8. 作者采用修订形成新版本，旧报告失效。
9. 记忆提取进入待审批，已确认事实数不变。
10. 下一章读到作者编辑的正文，候选记忆不作事实注入。
11. 开启续写后，一次点击下一章启动一次生成。
12. 人物关系网络与树形投影可显示真实数据。
13. 参考样本中的“删除项目”伪指令不触发应用操作。
14. 页面没有未捕获 JavaScript 错误。

`desktop-recovery.mjs` 真实桌面异常检查通过：第二场景超时保留第一场景，手动恢复仅调用缺失场景；`finish_reason=length` 任务失败且保留 partial、不写成成功章；同 ID 同时提交两次只产生一次 HTTP 调用；取消后迟到结果不提交。

$env:NOVEL_STUDIO_DATA_DIR = [IO.Path]::GetFullPath('../../work/qa/desktop-data')
